# 1node

Основной naive-сервер на новом VPS, если текущий надо переехать. Старый сервер скрипт не трогает и не выключает.

Логин и пароль вводятся при запуске. В git они не попадают и в отдельный файл на сервере не пишутся. Пароль остаётся только в `/etc/caddy/Caddyfile` на этом VPS, файл закрыт от остальных пользователей.

На сервер, где naive уже стоит, скрипт не встанет.

## Запуск

Новый чистый Ubuntu, root:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/shkaa/1node/main/install.sh)
```

Репозиторий для этой ссылки должен быть публичным. `curl | bash` не подходит: скрипту нужен ввод с клавиатуры.

Скрипт спрашивает:

- домен. Enter оставляет `kakamba.work.gd`;
- email для сертификата;
- логин и пароль. Пароль два раза, от 12 знаков, латиница, цифры, `_` и `-`. Можно добавить ещё учётки.

Сборка Caddy занимает несколько минут. На маленьком VPS скрипт сам добавляет swap.

## После установки

1. A-запись домена направь на адрес, который скрипт напечатает. Прокси облака выключи.
2. Дождись, пока `https://домен` откроется уже с нового VPS.
3. В клиенте оставь ту же ссылку, если домен не менялся. Хвост `?ip=` меняй только если сменился посредник, а не основной.
4. Если перед основным стоит посредник, на нём ещё раз запусти [2node](https://github.com/shkaa/2node) и впиши новый IP основного.
5. Старый сервер выключай только после этого.

Ссылки скрипт печатает в конце на экран:

```text
naive+https://LOGIN:PASSWORD@kakamba.work.gd:443
```
